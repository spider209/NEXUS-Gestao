# NEXUS Gestão — site demonstrativo

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.

Não precisa instalar nada: HTML, CSS e JavaScript estão no próprio arquivo.

## O que já funciona
- Layout responsivo para desktop e celular.
- Menu de navegação.
- Botões de entrar e solicitar demonstração com formulários demonstrativos.
- Cartões de recursos e painel visual de exemplo.

## Importante
Este é um protótipo front-end. Login real, cadastro, banco de dados, relatórios reais, integrações e envio dos formulários precisam de um backend e de regras de negócio.
